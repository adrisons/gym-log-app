# ADR-0002: Cross-platform native app

**Date:** 2026-09-08
**Status:** Superseded by [ADR-0002-revised](./ADR-0002-revised-pwa-and-storage.md)

## Context

The application must target both iOS and Android from a single codebase.

## Decision

Cross-platform: one shared codebase targeting iOS and Android as native
apps. The concrete framework was left open for a later `/plan` step.

## Consequences

Superseded before implementation began — see ADR-0002-revised. This record
is kept for history; it must not be treated as current.
